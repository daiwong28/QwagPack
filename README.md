# QwagPack 1.25.5-
*To make the game somewhat tolerable in 2025...*

## 🎯 Purpose
**QwagPack** is a resource pack for the QwagMC Minecraft server. But also attempts to retvrn to when the game was actually fun. Using 1.7.10 as a standard.

- 💎 Fine tuning some missed aspects of Minecraft back into the game
- 🧹 Removing unpopular corporate jargon 
- 🌙 Adding a darker GUI for playing at night

## 📦 Features
- Splash texts re-include mentions of Notch and removal of political messages, (it's a video game come on...)
- Dimmed or darker textures for most GUI.
- Old dirt backgrounds and title panorama's are reintroduced
- "Java Edition" title removed from main title 

## 🚀 Installation

1. Download the latest `.zip` from [Releases](#)  
2. Open Minecraft > *Options* > *Resource Packs*  
3. Click *Open Pack Folder*  
4. Move the `.zip` file into the folder  
5. Enable **BetterCraft** in the Resource Pack menu  

🎉 Enjoy a cleaner, more beautiful Minecraft!

## 🛠 Compatibility
- ✅ Minecraft **1.25.5-**  
- ❌ Not tested with shaders  
- ❌ Not a mod — purely a **resource pack**
